# ray-query/DXR: FULL inline ray query + DXR 1.1 tier gate

## 1. FULL VULKAN INLINE RAY QUERY (ray-query) - GREEN
5/5 consistent: `INLINE RAY QUERY (FULL VULKAN PATH) WORKS`, hit at minD=5.000
(the EXACT ray parameter for the triangle at z=-5 from the origin (2,2,0)).
The final bug was the accidentally-deleted tdesc.instanceDescriptorBuffer line
(the TLAS built with zero instances). Complete fix stack (all committed):
1. Discrete AS descriptor sets (the AS as a direct [[buffer(N)]] resource)
2. MTL4 argument-table dispatch + PSO warm-up (the first MTL4 dispatch with a
   PSO silently drops its writes)
3. Output staging through standalone shared buffers + blit copy-back
4. BLAS opaque=NO (opaque=YES BLASes are un-traversable on this beta)
5. TLAS instance transform 4th column zeroed (VK 3x4 has no 4th row)
6. TLAS instance buffer bound to the descriptor

## 2. DXR 1.1 TIER GATE (DXR first slice) - ENABLED
flprobe: `OPTIONS5 RaytracingTier=11` (DXR 1.1) via the inline ray query.
- vkd3d fork (2d71b20): the AS command APIs + barrier stages pass when either
  the RTPSO or the ray query feature is present; the tier computation falls
  back to tier 1.1 (inline ray query only, no TraceRay - state objects fail
  cleanly at creation).
- MVK (4cdc0d3):
  * AccelerationStructure feature flagCount 6 -> 5 (the struct has 5 VkBool32s;
    the extra read walked into the next feature struct and made vkCreateDevice
    fail with FEATURE_NOT_PRESENT)
  * rayTraversalPrimitiveCulling = true (inline traversal supports culling)
  * buffer features advertise ACCELERATION_STRUCTURE_VERTEX_BUFFER_BIT_KHR

## 3. 12_2 gate status after this work
The 12_2 feature-level gate (vkd3d device.c) needs, in addition to the
RaytracingTier 1.1 now cleared:
- ConservativeRasterizationTier >= 3 (the MVK reports tier 1 via emulation)
- DepthBoundsTestSupported (Metal lacks setDepthTestMinBound on Apple9/GPU)
- VariableShadingRateTier >= 2 (VRS and sampler feedback)
- MeshShaderTier >= 1 (mesh)
- SamplerFeedbackTier >= 0.9 (VRS and sampler feedback)
Plus the already-cleared gates: SM 6.5, WaveOps, Int64ShaderOps, binding tier 3,
tiled tier 4, VPAndRTArrayIndex, CopyQueueTimestamps, CastingFullyTypedFormat.

## MeshShaderTier cleared (2026-08-15)
VK_EXT_mesh_shader extension + meshShader/taskShader features advertised
(Metal 4 mesh/object support; SPIRV-Cross MSL mesh emission exists). flprobe:
MeshShaderTier=10. The MVK mesh pipeline machinery (mesh/task stages) is the
pending mesh work; pipelines fail cleanly until it lands.

## Remaining 12_2 gates (mapped 2026-08-15)
- DepthBoundsTestSupported: the MVK gates depthBoundsTest on the Apple10 GPU
  family; the GPU is Apple9 - the native setDepthTestMinBound is unavailable.
  The emulation (fragment-shader depth discard injection) is pending.
- ConservativeRasterizationTier >= 3: the vkd3d's gate needs
  fullyCoveredFragmentShaderInputVariable (the MVK's CR emulation reports
  tier 1).
- VariableShadingRateTier >= 2 (VRS and sampler feedback): the MVK has no VK_KHR_fragment_shading_rate.
- SamplerFeedbackTier >= 0.9 (VRS and sampler feedback): the vkd3d gate needs
  shaderImageInt64Atomics (Metal lacks 64-bit image atomics; the 32-bit
  encoding emulation is pending).
Cleared so far: RaytracingTier 1.1, MeshShaderTier 1, SM 6.5, WaveOps,
Int64ShaderOps, binding tier 3, tiled tier 4, VPAndRTArrayIndex,
CopyQueueTimestamps, CastingFullyTypedFormat.
